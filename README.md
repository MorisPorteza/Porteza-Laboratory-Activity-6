# Laboratory Activity #6: Smart Home Control System

## Overview
This activity implements a Smart Home Control System using Java. The program
models different smart devices inside a home and demonstrates how polymorphism
allows each device to behave differently while sharing a common parent type.

## Features
- Create multiple smart devices with unique states and behaviors
- Turn devices on and off with device-specific behavior
- Adjust and display device attributes when powered on
- Encapsulate device attributes and display status after updates
- Control multiple devices using a parent-type collection
- Count how many devices are currently powered on

## Classes Used
- Device
- AirConditioner
- LampShade
- Television
- Microwave
- SmartHomeMain

## Methods Used
- powerOn()
- powerOff()
- displayStatus()
- Setter methods for device attributes
- Static device control methods

## OOP Concepts Applied
- Method Overriding
- Polymorphism
- Runtime Binding
- Encapsulation
- Parent-Type References
- Arrays or Lists of Parent Type
